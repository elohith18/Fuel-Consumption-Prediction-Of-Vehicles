- Jupyter Notebook

- Data Cleaning & Preprocessing
- Linear Regression Model

- Interactive Dashboard

## 📁 Files

- Auto_MPG_Dashboard.pbix
- Dataset

## 📈 Results
- Achieved high prediction accuracy using Linear Regression
- Visualized insights using Power BI dashboard
